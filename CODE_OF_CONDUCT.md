# Code of conduct

Scroll Mage follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the work and not the person, and no harassment of any kind.

If behavior in this project's issues, pull requests or discussions breaks that standard, report it with GitHub's **Report content** option on the comment, or contact the repository owner through their GitHub profile. Reports are handled privately.
